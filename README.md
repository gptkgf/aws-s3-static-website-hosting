# AWS S3 Static Website Hosting

## Project Overview

This project demonstrates how to host a static website using Amazon Web Services (AWS) S3. It covers bucket creation, file uploads, versioning, public access configuration, and static website hosting.

The project was completed as part of my hands-on cloud computing learning journey.

## Objectives

* Create and configure an Amazon S3 bucket.
* Upload and manage files in cloud storage.
* Enable bucket versioning to maintain multiple versions of objects.
* Host a static website using Amazon S3.
* Configure public access and bucket policies.
* Understand the fundamentals of cloud storage and website deployment.

## Technologies Used

* Amazon Web Services (AWS)
* Amazon S3
* HTML
* JSON (Bucket Policy)

## Features

### 1. S3 Bucket Creation

Created an S3 bucket to store and manage project files.

### 2. File Upload

Uploaded five sample files with different extensions to demonstrate object storage.

### 3. Bucket Versioning

Enabled versioning and uploaded modified files to verify that previous versions were retained.

### 4. Static Website Hosting

Configured Amazon S3 to host a static website using `index.html` as the index document and `error.html` as the error document.

### 5. Public Access Configuration

Configured bucket permissions and a bucket policy to allow public read access to website objects.
